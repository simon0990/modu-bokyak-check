## ⚠️ 검수 전 데모입니다

이 페이지의 상호작용 정보는 **아직 약사 검수를 받지 않은 예시 데이터**입니다.
사용자 흐름과 화면을 확인하려고 만든 시제품이며, **실제 복약 판단에 쓰면 안 됩니다.**

- 이 결과는 진단이 아니며, 의사·약사의 판단을 대신하지 않습니다.
- 복용량, 복용 시점, 기저질환은 반영하지 않습니다.
- 확인된 주의 신호가 없다는 것이 모든 위험이 없다는 뜻은 아닙니다.
- 약을 바꾸거나 끊는 판단은 반드시 의사·약사와 상의해 주세요.

30·40대 버전에는 임신·수유 중 금기 항목이 포함돼 있습니다. 약리적으로 널리 알려진 내용이지만
**약사 검수를 거치지 않았으므로**, 검수 전에는 이 링크를 팀 밖으로 배포하지 않습니다.

## 두 버전의 차이

### 30·40대 버전 (`3040.html`)

- **영양제를 먼저** 묻고 처방약·기본정보를 합쳐 **2단계**로 끝냅니다
- 결과에 **조합 유형**(미니멀 베이스 / 핀포인트 / 풀케어 / 스택 빌더)과 4축 그래프가 나옵니다
- 공유 카드에는 **약 이름을 싣지 않습니다** — 유형·건수·등급 분포만
- 어두운 화면, 캐주얼한 말투

### 50대 이상 버전 (`senior.html`)

- 본문 20px, 터치 영역 64px, 한 화면에 한 질문
- 결과 화면에서 **「약사님께 여쭤볼 것」**을 두세 줄로 정리 — 약국에서 대화가 짧게 끝나도록
- 앱과 같은 디자인 토큰 유지, 신뢰감 있는 표현 중심

## 구성

파일 하나가 각각 완결되어 있습니다. 외부 요청이 없어 어느 정적 호스팅에나 그대로 올라갑니다.

```
index.html      버전 선택 페이지
3040.html       30·40대 (SNS)
senior.html     50대 이상 (약국)
original.html   2026-08-12 원본
```

- 프레임워크·빌드 도구 없음, 바닐라 JS
- 상호작용 규칙은 파일 안 한 곳에 데이터로 모여 있어, 검수 후 그 블록만 교체하면 됩니다
- 정적 검증은 `check.mjs`(로컬 작업 폴더)에서 — 외부 요청 0건, 금지 문구, 초록 사용, 데모 표식을 검사합니다

### 결과 링크 주의

선택한 내용이 주소 뒤(`#`)에 담깁니다. 즉 **결과 링크에는 고른 약·영양제·특이사항이 그대로 들어 있습니다.**
본인이 다시 열어보는 용도이며, 공개적으로 뿌리면 민감정보가 노출됩니다.
30·40대 버전은 이 때문에 공유 버튼이 결과 링크가 아니라 **서비스 주소만** 보내도록 분리해 두었습니다.
